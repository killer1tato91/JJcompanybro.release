4. Información que debes incluir

Para ayudarnos a investigar más rápido, incluye:

  • Nombre de usuario.
  • Correo registrado.
  • Versión de J&J Trading Tools.
  • Sistema operativo: Windows o macOS.
  • Descripción clara del problema.
  • Pasos realizados antes del error.
  • Captura del error, cuando corresponda.
  • Fecha y hora aproximada del problema.
No compartas información sensible

Nunca envíes tu contraseña, API key completa, códigos de verificación, datos bancarios, números completos de tarjeta ni credenciales de brokers o firmas de fondeo.

5. Problemas de inicio de sesión

Si no puedes iniciar sesión, verifica primero:

  • Que el correo o nombre de usuario sea correcto.
  • Que no existan espacios antes o después del texto.
  • Que la contraseña respete mayúsculas y minúsculas.
  • Que tu conexión a internet esté activa.
  • Que estés utilizando la versión más reciente.

Si el problema continúa, contacta a soporte desde el mismo correo registrado.

6. Problemas con NinjaTrader o el AddOn

Cuando el problema esté relacionado con NinjaTrader, incluye también:

  • Versión de NinjaTrader 8.
  • Nombre de la cuenta afectada.
  • Tipo de conexión utilizada.
  • Mensaje exacto mostrado en el Log.
  • Confirmación de que el AddOn está instalado.
  • Confirmación de que la API key es válida.

7. Suscripciones y pagos

Para consultas de suscripción incluye:

  • Correo de la cuenta.
  • Fecha aproximada del pago.
  • Referencia de la transacción, si está disponible.
  • Descripción del problema.

No envíes números completos de tarjetas ni códigos CVV.
